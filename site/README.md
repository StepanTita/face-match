# facematch landing page

Marketing landing page for facematch, built with Next.js (App Router) + TypeScript.

## Development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Build

```bash
npm run build
```

## Deploying

When deploying this site to Vercel, set the project's **root directory** to `site/` (this
directory lives inside the larger `face-match` repo, which is otherwise a Python `uv`
workspace for the CLI tool).
